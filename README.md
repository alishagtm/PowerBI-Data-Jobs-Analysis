# 📊 Data Jobs Analysis — Power BI Dashboard

## 📌 Project Overview

This project analyzes data job postings to understand trends in the data analytics and technology job market.

The interactive Power BI dashboard explores job roles, salaries, required skills, job locations, and other characteristics of data-related positions.

The goal of this project is to turn raw job-posting data into meaningful insights that can help job seekers better understand the current data job market.

---

## 🎯 Project Objectives

The main objectives of this project are to:

* Analyze the demand for different data-related job roles
* Explore salary trends across different positions
* Identify the most in-demand technical skills
* Compare job opportunities across locations
* Understand which roles and skills are most valuable in the data job market
* Build an interactive and easy-to-understand Power BI dashboard

---

## 📈 Dashboard

The Power BI dashboard provides an interactive view of the data job market.

Key areas analyzed include:

### Job Roles

Analysis of different data-related positions and their demand.

### Salary Analysis

Comparison of salaries across different job roles and other relevant categories.

### Skills Analysis

Identification of technical skills that appear most frequently in data job postings.

### Location Analysis

Analysis of where data-related job opportunities are concentrated.

### Job Market Trends

Exploration of patterns and trends within the available job-posting data.
